# Roadmap

This template stays reusable while providing production-grade repository foundations and a root-native Ubuntu Workshop automation baseline.

## Foundation

- [x] Repository documentation baseline
- [x] Security and contribution policies
- [x] Issue and pull request templates
- [x] CI and security workflow baseline
- [x] Dependabot configuration
- [x] Tag-driven GitHub release workflow with generated notes
- [x] Docker and task-runner placeholders
- [x] Architecture and development documentation structure
- [x] Root Ubuntu Workshop automation, installer, and non-mutating smoke checks
- [x] Project and GitHub documentation for Workshop operation
- [x] Complete four-part Ubuntu Workshop tutorial integration and fixtures
- [x] Explicit SDKcraft installation/refresh and project-aware passthrough
- [x] Current GitHub Actions major versions

## Future optional modules

- [ ] Language-specific starter packs
- [ ] Infrastructure-as-code starter packs
- [ ] Kubernetes and Helm starter packs
- [ ] SBOM and provenance workflows
- [ ] Release signing and artifact attestation
- [ ] OpenSSF Scorecard workflow
- [ ] Container vulnerability scanning
- [ ] Documentation site starter
- [ ] Monorepo profile
- [ ] Service/API profile
- [ ] Web application profile
- [ ] Library/SDK profile

Generated repositories should adopt only the modules appropriate to their stack and threat model.
